# Revise

Use this skill when the user has reviewer comments, critique findings, or revision instructions to classify and execute.

For detailed migration-source behavior, read `../../references/legacy-skills/revise.md`.

## Workflow

1. Classify each issue as analysis, clarification, rewrite, disagreement, or minor.
2. Route each item to the right worker-critic path.
3. Save response artifacts and revision logs under `quality_reports/`.
4. Keep disagreements explicit and user-reviewable.
