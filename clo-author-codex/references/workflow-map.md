# Workflow Map

This plugin preserves the original clo-author workflow families while translating them to Codex-native skills and hook-driven automation.

| Workflow | Purpose | Primary outputs |
|----------|---------|-----------------|
| `new-project` | Initialize research repositories | `AGENTS.md`, `clo-author.toml`, folder skeleton |
| `discover` | Interview, literature, and data discovery | `quality_reports/` discovery artifacts |
| `strategize` | Identification and design memos | strategy memo, robustness plan |
| `analyze` | Data engineering and analysis | scripts, tables, figures |
| `write` | Manuscript drafting | paper sections, revisions |
| `review` | Worker-critic and referee review | review reports, quality scores |
| `revise` | R&R or report response routing | change lists, response letters |
| `talk` | Slide and talk generation | talk files, audits |
| `submit` | Final package and gatekeeping | replication package, submission checklist |
| `tools` | Compile, validate, inspect workflow state | utility outputs |
