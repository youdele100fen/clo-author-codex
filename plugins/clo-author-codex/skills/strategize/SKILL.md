# Strategize

Use this skill when the task is about identification, design choices, falsification tests, or a strategy memo.

For detailed migration-source behavior, read `../../references/legacy-skills/strategize.md`.

## Workflow

1. Load the current project context from `AGENTS.md`, `clo-author.toml`, and relevant reports.
2. Draft a strategy memo or design response.
3. Run the critic pass against assumptions, inference, and robustness.
4. Save the result under `quality_reports/`.
