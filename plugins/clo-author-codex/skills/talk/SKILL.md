# Talk

Use this skill when the user wants a job-market talk, seminar deck, short talk, lightning deck, or slide audit.

For detailed migration-source behavior, read `../../references/legacy-skills/talk.md`.

## Workflow

1. Derive slide content from the paper and verified results.
2. Produce the slide artifact in `paper/talks/` or `paper/quarto/`.
3. Run a critic pass focused on structure, readability, and fidelity to the paper.
4. Save any talk audit under `quality_reports/`.
