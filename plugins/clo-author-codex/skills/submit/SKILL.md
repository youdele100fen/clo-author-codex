# Submit

Use this skill when the user is preparing for submission, final packaging, or replication auditing.

For detailed migration-source behavior, read `../../references/legacy-skills/submit.md`.

## Workflow

1. Confirm current quality gate status.
2. Build or inspect the replication package and supporting docs.
3. Trigger final review evidence and readiness reporting.
4. Save the outcome and any blockers to `quality_reports/`.
